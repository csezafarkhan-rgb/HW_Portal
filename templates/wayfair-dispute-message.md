# Wayfair deduction dispute — message template

Write the description as **short separate lines, not a paragraph**. The ticket view shows the text as one
block, so one fact per line is far easier for the Wayfair agent to check.

```
Deduction ID: <id>
PO: <po number>
Part ordered: <part number> — <what Wayfair lists it as>, <colour>, <size>
What we shipped: <item actually dispatched, with evidence reference>
Customer reported: <quote the customer comment in one line>
Why this deduction is wrong: <one line>
Evidence: <photos attached / dispatch record / packing photo — or "no photos were attached to this deduction">
Request: <reverse the deduction / send the customer photos so we can investigate>

Thank you,
Zafar K.
Ecom Manager
Home Weavers Inc.
```

## Notes
- Disputes must be filed in the **Deductions tool within 14 days** of the deduction appearing. After it
  settles, use Payment Details instead.
- Filing a dispute **pauses the settlement date** and Wayfair responds within 72 hours.
- Include the SUID (19440) in the body when asking for account-level action.
- Only dispute what we can evidence. Customer returns are normally valid; mis-shipments, naming
  mismatches and deductions with no photo evidence are the disputable ones.
