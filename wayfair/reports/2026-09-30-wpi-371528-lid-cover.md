## Problem 1: the dimension image is from a different set

The dimension image on FBWX1454 labels the second rug **24" wide x 17" high**. That piece does
not exist in this set.

Our catalogue has four different 4-piece sets, each on its own listing:

| Size combo | Listing | Product |
|---|---|---|
| 17-21-20-22 | DRBH6308 | Morissette 4-Piece Bath Rug Set |
| **17-21-24-22** | **DRBH6313** | **Morissette 100% Cotton — this is the set with a 24" piece** |
| 18-17-21-22 | FBWX1425 | Delean 4 Piece |
| **18-20-21-22** | **FBWX1454** | **Waterford 4 Piece with Lid Cover — our ticket** |

The 24" piece belongs to **DRBH6313**. The image on FBWX1454 should show **21" x 34"**.

So a customer on this listing is being shown the wrong second rug, at the wrong size, in the
wrong shape. That is a mis-information incident waiting to happen on every order, and it is
more serious than the question Wayfair actually asked.

## Problem 2: the specifications never mention the lid cover

Read live today:

| Spec field | Current value | Verdict |
|---|---|---|
| Total Number of Pieces Included | 4 | correct |
| Number of Bath Rugs Included | 2 | **correct** — the 21x34 and the 22x60 |
| **Pieces Included** | **"Bath Rug"** | **wrong — omits the contour rug and the lid cover** |
| Product Type | Bath Rug | should be Bath Rug Set |
| **Subject** | **"Nautical & Beach, Animals"** | wrong — solid colour, no motif |
| Overall Shape | Runner | describes one piece, not the set |

And the **description never lists the contents**:

> "Indulge in Everyday Luxury with Our Waterford Collection Plush Bath Rug... this rug boasts a
> sumptuously soft and plush texture..."

Singular throughout. It describes one rug.

So the only place on the entire page that says "lid cover" is the title. The spec field that
exists precisely to answer "what's in the box" — Pieces Included — says "Bath Rug".

**Caveat:** this assumes the set was packed correctly. If the customer genuinely received three
pieces, that is a packing issue and we should pull the PO. Wayfair filed this as
"Update Request: Feature Bullet / Media", so they are treating it as listing accuracy.
