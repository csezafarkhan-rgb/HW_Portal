# Credit 62425410 (PO CS682443126) — the listing fix

Customer refunded on BWA2020CSA because "the online description is sage. This rug says green and
it isn't even green." We shipped the right rug; the defect is in the naming.

## What is actually wrong, verified on the listing

**Listing FBWX1491 — "Morissette 100% Cotton Contour Mat 20"x20"", 19 colour variants.**
Live on four stores: wayfair.com B2C and B2B, **and wayfair.ca B2C and B2B**.

| Problem | Detail |
|---|---|
| Collection mismatch | Title says **Morissette**. The pack says **Waterford**. The *description* already says "Waterford Collection" six times — so the listing contradicts itself. |
| Colour mismatch | SA shows on site as **Sage**; the barcode sticker says **Green**. |
| Pre-existing colour inconsistency | The same listing already has GRFT = **"Forest Green"**. So "Green" alone is not available as a value — it would read as a second, different green. |
| Other odd colour names | YE = **"Butter"** (not Yellow), RB = **"Navy Blue"**. Same class of defect, not yet complained about. |

BWA2020CSA is not a dead SKU — $130.58 revenue, 17 units in the last 90 days, +56.2%. The listing
carries 638 reviews at 3.83.

## The fix

1. **Product name** → `Waterford 100% Cotton Contour Bath Mat, Spray Latex Backing, 20"x20"`
   Puts Waterford in front of the customer so the pack is recognisable. Keeps colour out of the
   title (colour is chosen on site). Uses "Spray Latex Backing", not "Non-Slip", per the cotton
   range rule.
2. **Colour value for SA** → `Sage` becomes **`Sage Green`**
   Carries both the listing word and the packaging word, and does not collide with GRFT's
   "Forest Green".
3. **Optional, same root cause** → YE `Butter` becomes `Yellow`.

## Status: not yet applied — the self-service routes did not work

- **Groups tab** only exposes the *group* name ("Color") and display order. It does not list the
  per-variant option values, so "Sage" cannot be edited there, despite what help article 3183
  implies.
- **Content → Attributes → Edit** on the variant does not render editable fields.
- **Update from File → Bulk Update Product Names / Bulk Update Variant Groups** is the right
  route, but it needs Wayfair's own exported template — it carries `md5Hash` and `Exported_*`
  columns that cannot be hand-built safely.
- **Export All** on the filtered listing did not queue a job. The row checkboxes do not tick and
  nothing new appeared in the Download Center.

**To unblock:** export FBWX1491 from Product Management (Select All, then Export All) and the file
lands in Download Center as a "Product Description Export". Hand that over and the edit is a few
minutes' work, same as the Waterford 4PC copy update on 30 Sep which went through 19/19 clean.

## Note on the deduction itself

The reversal argument is already made in the ticket and is sound — the customer's own photo shows
the correct rug. Nothing in the listing fix weakens it; it is the recurrence prevention.
